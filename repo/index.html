os-uplink-speedtest

A FreeBSD package repository for the OPNsense uplink speedtest plugin. Add it once on the firewall; after that the plugin installs and updates from System → Firmware → Plugins like any other.

Add the repository (as root, once)

mkdir -p /usr/local/etc/pkg/keys
fetch -o /usr/local/etc/pkg/keys/uplink-speedtest.pub https://chanclatoen.github.io/opnsense-uplink-speedtest/uplink-speedtest.pub
fetch -o /usr/local/etc/pkg/repos/uplink-speedtest.conf https://chanclatoen.github.io/opnsense-uplink-speedtest/uplink-speedtest.conf
pkg update

What you are trusting

The repository metadata is signed with an RSA key that never leaves its owner's machine. uplink-speedtest.pub is the matching public key; its SHA-256 is

2ea52dff8771fea1305303ba29d1b2f04484ae084cf3ea79e1419bee558ef9a6

The same value is printed in the project README, so you can compare the two before you trust either. The signed metadata carries the checksum of every package, so a package that was not built by this repository's workflow cannot be installed from it.

Packages are built for FreeBSD:14:amd64, which is what OPNsense 26.x runs. The repository priority is below OPNsense's own, so it can never shadow an official package.
